WorkBridge- Connecting Skilled People With Task Seekers

WorkBridge is a full-stack freelancing platform designed to solve a real-world problem — connecting skilled individuals with people who need work done.

Many people have skills but lack opportunities, while others struggle to find reliable workers. WorkBridge bridges this gap by providing a structured and simple workflow.

Tech: Java, Opps, Spring Boot, REST APIs, React, PostgreSQL

🌐 Deployed On: Vercel (Frontend) + Render (Backend)

👤 User Flow: Post task → visible in marketplace → freelancer accepts → payment initiated → work completed → result delivered

💼 Freelancer Flow: Browse tasks → accept → work step-by-step → submit → get paid after approval

🔐 Includes structured workflow, role-based access, and scalable backend architecture.
